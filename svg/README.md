# HakiWork 哈基米 SVG 素材库

> 统一设计规范：极简单线风格，薄荷青 `#84C9BF` 线条，无大面积填充，圆润柔和。
> 所有素材适配「清新淡雅 + 轻度磨砂商务」融合风格，萌感克制点缀，不卡通低幼。

## 设计规范

| 项目 | 规范 |
|------|------|
| 线条颜色 | `#84C9BF`（低饱和薄荷青） |
| 线条宽度 | 2 ~ 2.5px（小图标 2px，主插画 2.5px） |
| 填充 | 默认无填充，仅鼻子等极小区域使用实色填充 |
| 圆角 | `stroke-linecap="round"` / `stroke-linejoin="round"` |
| 风格 | 极简单线，圆润柔和，无写实、无卡通厚涂 |
| 适用场景 | 办公软件界面，点缀式使用，不铺满页面 |

## 素材清单

### 1. `logo-hakimi.svg`
- **用途**：左侧导航顶部 Logo 图形标，搭配文字 "HakiWork" 使用
- **尺寸**：200 × 200 viewBox，建议实际显示 28~40px
- **描述**：坐姿小动物正面轮廓，闭眼微笑，胡须、卷尾齐全，整体圆润饱满
- **交互建议**：hover 时可加轻微缩放/呼吸动效

### 2. `empty-state.svg`
- **用途**：各页面空状态插画（无插件、无任务、无数据时展示）
- **尺寸**：240 × 200 viewBox，建议实际显示 160~200px 宽
- **描述**：坐姿哈基米抬头好奇张望，旁边一个虚线空文件框 + 问号气泡
- **搭配文案**：「暂无快捷工具，去添加插件解放重复工作吧」

### 3. `loading.svg`
- **用途**：全局加载动画、插件安装加载、数据请求 Loading
- **尺寸**：120 × 120 viewBox，建议实际显示 48~64px
- **描述**：哈基米头部 + 尾巴，内置 CSS 呼吸动画（头部 1.8s 缩放循环，尾巴 1.2s 摆动）
- **注意**：已内嵌 `<style>` 动画，直接引用即可生效；如需禁用动画可移除 style 标签

### 4. `success-toast.svg`
- **用途**：操作成功提示 Toast 角落小图标
- **尺寸**：64 × 64 viewBox，建议实际显示 20~28px
- **描述**：迷你哈基米头部 + 右下角对勾，外圈虚线装饰
- **搭配文案**：「搞定啦，哈基米帮你省下不少时间」

### 5. `corner-decor.svg`
- **用途**：页面边角低透明度装饰（插件市场底部、个人中心角落）
- **尺寸**：160 × 160 viewBox，建议实际显示 80~120px，`opacity: 0.5`
- **描述**：蜷缩睡觉的哈基米，带 Zzz 气泡，文件本身已设 0.5 透明度
- **注意**：仅作背景点缀，不可遮挡功能内容，不建议在首页工作台使用

### 6. `sleeping.svg`
- **用途**：待机/休息状态插画、无任务时的轻松提示页
- **尺寸**：200 × 160 viewBox，建议实际显示 180~220px 宽
- **描述**：趴卧睡觉的哈基米，前爪垫头，闭眼安详，带 Zzz 气泡
- **搭配文案**：「暂时没有任务，哈基米先歇会儿」

### 7. `working.svg`
- **用途**：任务执行中、插件运行中、首页工作台欢迎插画
- **尺寸**：220 × 180 viewBox，建议实际显示 200~240px 宽
- **描述**：哈基米坐在电脑前专注敲键盘，半眯眼认真表情，屏幕有内容线条
- **搭配文案**：「哈基米正在帮你处理重复工作」

## 使用原则（和伙伴约定，防止越界）

1. **点缀式使用**：哈基米形象仅出现在 Logo、空状态、Loading、成功提示、边角装饰，功能卡片主体、导航按钮、表单区域不添加萌系图案
2. **统一线条语言**：所有形象保持同一套极简单线风格，不混用插画、emoji、厚涂
3. **不做光标/漂浮元素**：禁止把哈基米做成鼠标光标、页面漂浮动画
4. **色彩克制**：统一薄荷青线条，不使用高饱和多色填充
5. **尺寸适配**：引用时通过 CSS `width/height` 控制显示尺寸，保持 `viewBox` 等比缩放

## 开发引用示例

```html
<!-- Logo -->
<img src="/svg/logo-hakimi.svg" alt="HakiWork" width="32" height="32" />

<!-- 空状态 -->
<img src="/svg/empty-state.svg" alt="" width="180" />

<!-- 加载动画 -->
<img src="/svg/loading.svg" alt="加载中" width="48" height="48" />
```

```css
/* 边角装饰定位 */
.corner-decor {
  position: absolute;
  bottom: 16px;
  right: 16px;
  width: 96px;
  opacity: 0.5;
  pointer-events: none;
}
```
