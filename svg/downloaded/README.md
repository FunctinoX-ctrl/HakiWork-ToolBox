## 三、与 HakiWork 风格的适配建议

### 推荐优先使用
1. **`manbo-green.png`** — 薄荷绿扁平曼波鱼，配色最贴合你们的 #84C9BF 主色调，简约无背景，适合做：
   - 插件图标变体
   - 加载动画（可做成上下浮动的 CSS 动画）
   - 空状态装饰
2. **`hakimi-lineart.png`** — 黑白线条风格，可直接用矢量软件描线转成 SVG，和之前的原创 SVG 素材风格统一

### 谨慎使用（风格冲突）
- `hakimi-ip-cat.png`、`hakimi-two-cats.png` — 粉彩手绘风，和清新淡雅+轻度磨砂的克制风格有冲突，建议仅做参考，不要直接放入界面
- `hakimi-mcdonald.gif` — 体积大（529KB）且魔性搞笑，容易破坏办公软件的专业感，建议仅作为隐藏彩蛋

### 曼波鱼做加载动画的方案
由于曼波鱼本身"呆萌、随波逐流"的网络梗，可以做成：
```css
.manbo-loading {
  animation: float 2s ease-in-out infinite;
}
@keyframes float {
  0%, 100% { transform: translateY(0) rotate(-3deg); }
  50% { transform: translateY(-8px) rotate(3deg); }
}
```
